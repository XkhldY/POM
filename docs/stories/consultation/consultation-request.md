# Story: Expert Consultation Request System

**Epic:** Consultation Request System  
**Priority:** Medium  
**Estimate:** 3 story points

## User Story

As a **job seeker**,  
I want **to request expert consultation for personalized career guidance**,  
so that **I can get professional help to further improve my resume and career prospects**.

## Acceptance Criteria

- [ ] Consultation request form with help category selection
- [ ] Email capture (extracted from resume or manual entry)
- [ ] Detailed help requirements and career goals input
- [ ] Integration with resume analysis results
- [ ] Confirmation message after submission
- [ ] Email notification to user
- [ ] Admin dashboard for consultation management
- [ ] Mobile-responsive form interface

## Technical Notes

- Create consultation request form with validation
- Implement email notification system
- Store requests in database with analysis association
- Add admin interface for request management

## Definition of Done

- [ ] Form submission working correctly
- [ ] Email notifications sent
- [ ] Admin dashboard functional
- [ ] Mobile interface tested
