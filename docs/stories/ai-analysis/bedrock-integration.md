**Epic:** AI Analysis Engine  
**Priority:** High  
**Estimate:** 8 story points

## User Story

As a **developer**,  
I want **to integrate AWS Bedrock for resume analysis**,  
so that **the system can provide intelligent, AI-powered improvement suggestions**.
